# WebWatch AI - Website Monitoring for B2B

🚀 Premium B2B Micro-SaaS nástroj na monitorovanie webov s moderným dizajnom a pokročilými funkciami.

## ✨ Features

✅ **Real-time Monitoring** - Sleduj zdravie svojich webov v reálnom čase  
✅ **Uptime Tracking** - Automatické sledovanie dostupnosti  
✅ **SSL Certificate Monitoring** - Upozornenia na expirujúce certifikáty  
✅ **Response Time Analytics** - Detailná analýza výkonu  
✅ **Interactive Dashboard** - Prehľadný a intuitívny interfejs  
✅ **Dark Mode Design** - Moderný premium dizajn inšpirovaný Linear/Vercel  
✅ **Responsive** - Perfektné na mobile, tablet aj desktop  

## 🛠 Tech Stack

- **React 18** - Moderný frontend framework
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Krásne SVG ikony
- **Vite** - Rýchly build tool
- **JavaScript (ES6+)** - Moderný JavaScript

## 🚀 Rýchly start

```bash
# Inštalácia závislostí
npm install

# Spustenie dev servera
npm run dev

# Build pre produkciu
npm run build

# Preview produkčného buildu
npm run preview
```

Aplikácia sa otvorí na `http://localhost:3000`
